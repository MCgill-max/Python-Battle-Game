# ⚔️ Python Battle Game

A text-based battle game built with Python using Object-Oriented Programming (OOP).

## About the Project

This project allows players to manage characters, battle against other characters, gain experience, level up, and save or load game progress.

## Features

- **Character Classes:** Warrior, Mage, and Archer.
- **OOP Concepts:** Inheritance and polymorphism.
- **Battle System:** Turn-based combat.
- **XP & Leveling:** Winners earn experience points.
- **Healing System:** Restore character health.
- **Battle History:** Keep track of battles.
- **Save & Load:** Store and restore characters using JSON.
- **Error Handling:** Handle invalid input and corrupted save files.

## Project Structure

- `main.py` — Main game code.
- `characters.json` — Saved character data.
- `.gitignore` — Files ignored by Git.

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder.
4. Run:

```bash
python main.py
```
